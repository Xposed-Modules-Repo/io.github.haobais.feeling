# Feeling

Feeling is a closed-source Xposed enhancement module by 皓白 (`haobais`).

## Supported hosts

- Douyin (`com.ss.android.ugc.aweme`)
- Douyin Lite (`com.ss.android.ugc.aweme.lite`)
- DuoShan (`my.maya.android`)
- NetEase Cloud Music (`com.netease.cloudmusic`)

The release assets are compiled APKs only. This repository does not contain the module source code.

## Variants

- Standard: libxposed entry point
- Legacy: Xposed API 51+ entry point
